## 2026-10-09（续）· 食物平衡修复（玩家反馈「过几天饿死」）

- **诊断先行**：流量测量（每段 tick 吃 vs 采集入账）显示稳态供给 0.79/tk < 需求 0.84/tk（慢性赤字 5~6%），叠加进食机制两个缺陷——①饥饿中断丢弃半程序程（效率损失近半），②库存击穿后全员挤在 eat 任务上「自产自销」互锁加速死亡。5 个种子复现：崩盘死亡 16~20 人。
- **架构修复**：进食从任务机剥离为 **tick 层涓涓流**（越过个人阈值 30~60 才吃 1 口，自动节流；库存地板 6 让位采集回款，hunger<15 濒死破例），任务与路径永不中断 → 互锁物理上消失。
- **参数**：采集 2 tick/单位、移速 0.18、携带 食16/木10/石10、消耗 0.18、再生 0.05、生育门槛 120、幼儿吃口更小（阈值机制天然自限）。
- **验收**：新增 `tests/food-balance.test.ts`（5 种子真实开局 10000 tick：饿死 ≤2、存活 ≥10，RED→GREEN）；死因拆分统计 starveDeaths/ageDeaths。修复后 5 种子饿死全部 =0，死亡全为自然老死；浏览器实测第 78 天 27 人 0 死亡、食物 1686、2 房。
- 全量 28/28 通过，构建通过。

## 2026-10-10 · 人口积累修复（玩家反馈「人口一直没办法积累」）

## 2026-10-13 · v0.3 大陆文明演化

根据反馈把重点从短局生存改为长期城市演化。新增 256×256 多生态大陆、五个时代与设施解锁、真实扣料的城市建设和住宅升级、道路、学校 / 集市 / 诊所 / 工厂 / 电站 / 高楼 / 采石场。研究与工业岗位需要成年人到达工作场所；钢材消耗木石并依赖电力；机械化农业与有限地下矿藏补上后期产能闭环。

人口采用统一的 365 天年龄时钟，18 岁成年，妊娠 270 天、产后至少两年；每 30 天按空余岗位 / 住房 / 粮食接纳移民，外部人口池有限。出生、迁入、死亡单独计账并检查人口恒等式。参数明确为游戏设计，未经现实数据校准。旧玩法继续保留，不自动毁掉存档或搬迁旧地图。

性能：采集按局部范围找资源；寻路优先校验直线；资源再生分桶；建筑计数、工作地点及人口数缓存；地形只重画变化地块；道路绘制限制可见区域。大地图存档使用无损 zlib 压缩，兼容旧版本。

阶段长测曾暴露粮食产能与石料供应瓶颈，已增加有电力条件的农业机械化和矿工开采有限矿藏。4000 天检查人口来源守恒、全部时代与大规模城区；浏览器验证手机无横向溢出、优先级、建设开关、地图总览、存档恢复和千人城市画面。

最终验证：64 项测试通过；生产路径构建通过。种子 42 从头运行 4000 天，完成五个时代，形成 304 座建筑与 1594 人的城市；初始 20 + 出生 204 + 迁入 1370 − 死亡 0 = 1594。采石场、供电与农业闭环均包含在此最终测试中。长测 175 秒，因此常规 CI 将其设为可选，不在每次提交时强制执行。
