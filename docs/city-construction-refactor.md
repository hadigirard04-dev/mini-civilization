# v0.7 城市形态重构（2026-10-17 本地完成）

用户明确反馈：城市形态和建筑布局不自然。本轮处理建设与画面的空间关系，物流等玩法保留为后续事项。保持自动发展、经济账本和 v4 存档可读；街道、宅地与居民使用可验证的空间规则。按用户最新要求，完成本轮后停止继续迭代。

## 已确认的问题

- 逻辑道路连通地块中心，画面却在地块边界画孤立线段；居民移动与可见道路不一致。
- 住宅从同一方格候选中随机抽取，密度升级同时重洗位置；一个住宅地块内几乎所有建筑同高。
- 布局只检查整块是否可建，不能阻止具体建筑压在块内的水面或山体上。
- 未开发森林、矿地会画出两间住宅，造成无人地带也像散布着居民。
- 扩张只连接一个邻居，缺少成形街区的回路；公共设施按人口重复铺开，后期挤占城区。

## 实施方向

采用「沿街生长的河湾城镇」：保留聚合地块作为经济单位，把街道、地块内建筑和居民动画统一到同一套空间几何。每个街道节点落在实际地形上，相邻节点经可行地面相连，跨水段明确画桥。建筑在街道两侧找可用宅地，保留院落、绿地与混合高度；未开发土地保留自然地形。布局随机数独立于人口与经济。

1. 建立可缓存、可测试的街道几何与沿街宅地布局，移除虚构小屋。
2. 道路、步行者、田地、建筑基底与施工过程共用几何；缩略图使用同一路径。
3. 调整规划器：住宅就近补齐街区、农业形成城外田片、工业形成独立片区；补充有意义的街道回路并升级主街。
4. 验证同档升级外观、早中晚期城市、不同种子、旧存档续跑、长程资源与性能；记录用户体验仍待验收。

## 长程反馈后补齐的用地规则

三种子长测确认：按失业人数继续新建工厂会把闲置工业铺满土地；矿石与木材产能不足时，仅保留库存下限也无法解除建设停滞。

- 工业扩张改为看钢材/石料的实际库存与产能缺口；已在建的工厂计入潜在产能。
- 城区保留够用的可采林地，不把所有临路空地当作可开发地。
- 支付材料并施工后，闲置厂地可改作电站/水厂；原有建筑保留到改造结束。
- 燃料产能不足时，原本位于森林地形上的闲置厂地可复育，恢复原料来源。复育项目也计入未来林地产能，避免重复启动。
- 电站按运行需求调度；停工产业不计满负荷用电。每日更新供电覆盖，确保保存后续跑一致。
- 供水设施与学校、公园一样，按实际缺口与受益居民选址。旧规则偏好远处水源并回避住宅，曾在一个长局中无效铺出 265 座水厂，已增加对应回归。

## 验收边界

- 自动检查建筑基底不压水/山、不重叠道路或其他建筑；居民位置位于实际绘制的街道路径上。
- 存档不必储存派生美术数据；同状态重建一致，不消耗模拟 RNG。
- 保留现有经济、规划不变量及旧测试；新增测试针对真实空间缺陷。
- 真实浏览器分别检查村落、城镇、现代城市的街道级与总览，并检查手机画幅与快进。
- 本地构建和预览完成后才替换 4180 的稳定产物；不自动 push 或公开发布。

## 完成结果

上述空间与建设规则已落地。132 项常规测试、3 种子各 24000 天、6 次精确存档续跑、旧档续跑与生产浏览器检查通过；验收命令、结果和限制见 `v07-verification.md`。实际截图为 `v07-city.png`。自动检查与截图复核不代表用户审美验收，实体手机未测试。
