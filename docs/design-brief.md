# 设计简报 · 微型文明（design-harness）

1. **解决什么问题 / 主行动**：让用户观察并干预一个自主运行的像素文明。最重要的操作是「看懂世界状态并控制时间」——开始/暂停/倍速是第一控制，点击地图与居民是第一探索动作。
2. **视线第一落点**：主地图（约占屏 75%），居民移动、资源增减、建筑落成是画面主角，必须最大、最先被看到。
3. **什么次要**：右侧窄栏（人口/资源/时间/统计曲线/选中详情）解释地图上发生的事，信息要清楚但视觉上退后一档；标题与装饰最安静。
4. **可去掉什么 / 布局**：去掉登录、卡片网格、徽章堆叠、图表仪表盘墙。布局 = 顶部细标题条 + 中央整块画布 + 右侧约 300px 固定栏，栏内用发丝线分区而非卡片。
5. **视觉方向**：独立像素模拟游戏——墨绿夜色底（#10140f 族）、羊皮纸文字（#e8e2d0 族）、苔绿做结构、琥珀 #e0a83c 做唯一强调（按钮/选中/关键数字），等高线母题贯穿侧栏背景（呼应地图主题）。最诱惑的 AI 默认样式是紫蓝渐变玻璃仪表盘——用扁平发丝线、克制配色、像素细节（锯齿边、dither 纹）替代。地图内采用自然地形色（草绿/林深绿/水蓝/石灰），与 UI 的暗色底形成层次。

字体：系统栈（Segoe UI + Microsoft YaHei），不引入远程字体；字号 12/14/16/20/28 五档；间距 4px 基准。
