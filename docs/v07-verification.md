## 生产浏览器

Chrome 1440×900，候选构建资源 `index-Ce-Kvm90.js`。完整 UI 检查输出 `browser-qa.json`：

- 从较早状态读取 12000 天档，暂停状态实速保持 0，不把日期跳转算成快进。
- 200× 运行 5.122 秒，实际推进 1009.57 天，约 197.1×；运行中 HUD 约 101 FPS / 199.2×。
- 暂停两次保存的 tick 都为 780574；研究政策与污染图层保存刷新后保留，按钮选中状态正确；未捕获页面脚本错误。
- 点击聚落名称能切换取景；390×844 画幅的页面宽度为 375px，主要切换按钮至少 44px，切换聚落会回到地图。
- 早期村落、中期城镇、后期现代城市的街道级/总览截图均实际查看。保留的文档图片 `v07-city.png` 来自真实浏览器，未拼造城市画面。

另以 5 秒 requestAnimationFrame 采样：约 3600 人时 165 FPS / 实际 198.46×，12 万人后期城市 136 FPS / 实际 197.83×，见 `browser-perf-mid.log` 与 `browser-perf-late.log`。这是本机短时表现，不能外推到手机。

测试宿主的 Windows 原生窗口遮挡曾使默认浏览器降到约 1 FPS，即使 visibilityState 仍为 visible。为区分宿主节流与应用负载，最终验收使用独立测试浏览器的禁后台节流启动参数，保存在 `perf-browser.json`；没有改用户浏览器或系统设置。默认后台测试日志保留用于诊断，不作为前台性能结果。

## 交付边界

实体手机与用户主观体验未验收。地图有限，十万人长局仍可能出现粮食压力和土地紧张；本轮解决无效设施扩张、闲置工厂占地及供电调度，不宣称无限时长的经济平衡。聚落资源仍用全局账本，居民仍为动画采样。

按用户「完成任务就停止」的最新要求，本轮本地入口、记录和提交完成后停止，不自动展开物流或下一版本。
